# 3.1 Product Discovery – SmartRent

## 1. Product Vision
SmartRent aims to be a rental property management system that enables landlords to centrally manage properties and tenants while using AI to support operations and tenant services.

## 2. Problem Statement
Rental properties are often managed through separate channels such as spreadsheets, messages, and notes. As the number of rooms grows, landlords struggle to track room status, contracts, rent, and maintenance requests. Tenants also have limited visibility into whether their requests have been received and how far they have progressed.

## 3. Target Users

### 3.1 Landlords / Property Managers
- Manage multiple rooms.
- Track tenants.
- Monitor contracts and rent.
- Receive and resolve incidents.
- Need timely reports and information.

### 3.2 Tenants
- View room and contract information.
- Track outstanding payments.
- Submit maintenance requests.
- Track request status.
- Receive prompt support when they have questions.

## 4. Pain Points

| User | Pain Point |
|---|---|
| Landlord | Management data is fragmented |
| Landlord | Difficulty tracking multiple rooms |
| Landlord | Time-consuming responses to recurring questions |
| Landlord | Difficulty prioritizing maintenance requests |
| Tenant | Must send manual messages when an issue occurs |
| Tenant | Cannot determine the processing status |
| Tenant | Difficulty finding contract and payment information |

## 5. Product Opportunities
- Centralized management dashboard.
- Room, tenant, and contract management.
- Maintenance request management.
- Automated notifications.
- AI chatbot.
- AI-based request classification and prioritization.
- AI-generated summaries for management purposes.

## 6. AI Opportunities
1. An AI Assistant that answers frequently asked questions.
2. AI-based maintenance request classification.
3. AI-based priority determination.
4. AI-generated summaries of tenant reports.
5. AI-assisted queries over management information.

## 7. MVP
The MVP focuses on core business functions and two AI capabilities:
- AI Assistant.
- AI-based maintenance request classification.

## 8. Success Metrics
- Reduce request processing time.
- Increase the rate of correctly classified requests.
- Reduce the number of recurring questions that landlords must answer manually.
- Enable tenants to track request status.
