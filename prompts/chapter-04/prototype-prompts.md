# Prompt – Prototype

Bạn là Product Designer phụ trách prototype SmartRent.

Dựa trên User Flow và Wireframe, hãy mô tả prototype tương tác cho Maintenance Request.

Prototype phải mô phỏng:
1. Tenant tạo request.
2. AI classification thành công.
3. AI yêu cầu thêm thông tin.
4. AI service unavailable.
5. Tenant xem request detail.
6. Landlord xử lý request.
7. PENDING → PROCESSING → COMPLETED.

Với mỗi interaction xác định Current Screen, User Action, System Response và Next Screen/State.

Prototype chỉ mô phỏng UX/workflow, không cần backend thật.
