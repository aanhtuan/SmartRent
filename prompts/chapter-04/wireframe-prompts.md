# Prompt – Wireframe

Bạn là UX/UI Designer.

Dựa trên User Flow và tài liệu Chapter 3 của SmartRent, hãy thiết kế low-fidelity wireframe cho Maintenance Request.

Bao gồm:
1. Tenant Dashboard
2. Maintenance Request List
3. Create Maintenance Request
4. AI Classification Result
5. Maintenance Request Detail
6. Landlord Maintenance Dashboard
7. Missing Information State
8. AI Unavailable State

Mỗi màn hình nêu mục tiêu, thành phần chính, primary action, navigation và error/empty state nếu có.

Không tập trung vào màu sắc; tập trung information architecture và interaction.

## Human Review
Kiểm tra navigation, primary actions, consistency với User Flow, error handling và AI transparency.
